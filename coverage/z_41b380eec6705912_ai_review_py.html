1"""Native AI code-review job (``praktika review``). 

2 

3Reviews a pull request with an LLM and posts the results back to GitHub. The 

4design keeps the model on a short leash: it is asked for a **structured result 

5only**. It may investigate the checked-out PR with read-only tools 

6(``read_file`` / ``grep_repo``), but it never acts on GitHub itself — it just 

7returns JSON describing what it found. 

8 

9**Trusted Praktika code** then applies that result: a top-level summary comment, 

10a single batched inline review, and resolve/unresolve/reply on review threads — 

11and only on threads the reviewing bot itself authored (ownership is enforced 

12here, in code, not trusted from the model). Because the model has no shell and 

13no write access, a prompt-injected diff cannot make it run arbitrary commands or 

14touch anything outside this bounded surface. 

15 

16Configuration is entirely via CLI args, so a consuming repo wires it as a plain 

17job command with no new config classes:: 

18 

19 Job.Config( 

20 name="Code Review", 

21 runs_on=RunnerLabels.SMALL_ARM, 

22 command="praktika review --provider bedrock-openai " 

23 "--model openai.gpt-oss-120b-1:0 --prompt ./ci/prompts/code_review.md", 

24 allow_failure=True, 

25 enable_gh_auth=True, 

26 ) 

27 

28The provider is any name in the AI registry (``mock`` / ``anthropic`` / 

29``bedrock-anthropic`` / ``bedrock-openai``); ``--model`` overrides its default model. 

30``--prompt`` points at a repo-local Markdown file with project-specific review 

31guidance, appended to the fixed review protocol. 

32"""

305 )

518def review(args): 

519 """Gather PR context, consult the model, and apply the structured result.""" 

520 info = Info() 

521 if not info.pr_number or int(info.pr_number) <= 0: 

522 print("Not a PR — skipping AI review") 

523 return Result.create_from(status=Result.Status.SKIPPED, info="not a PR")

526 if args.prompt: 526 ↛ 527line 526 didn't jump to line 527 because the condition on line 526 was never true

528 raise FileNotFoundError(f"Prompt file not found: {args.prompt}")

530 project_prompt = f.read() 

531 

532 provider = resolve_provider(args.provider, model=args.model or "")

543

547 # False (not raise) on API failure, so a failed/partial write must fail the 

548 # job rather than falsely report a successfully applied review.

552 errors += _post_inline_findings( 

553 review_data.get("inline_findings"), 

554 info.sha,

557 ) 

558 errors += _apply_thread_actions( 

559 review_data.get("thread_actions"), threads, args.dry_run 

560 ) 

561 

562 rounds = ""

564 rounds = (
